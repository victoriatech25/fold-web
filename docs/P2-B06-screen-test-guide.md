# P2-B06 원판·잔재 사용 화면 테스트 가이드

> 대상: [P2-B06 상세계획](./work-items/P2-B06-sheet-usage-remnant.md)
>
> 작성일: 2026-08-30
>
> 검수자: 사용자 본인
>
> 검수 결과: **미검수**

재단 결과가 처음으로 재단 밖으로 나오는 단계다. 승인이 곧 "원판을 썼다" 가 되고, 남은 조각이 다음 재단으로 돌아온다.

- **수주 상세 `승인·생산` 탭**: 그 수주가 쓴 원판
- **생산·출력 → 원판 사용 실적**: 기간·원판별 집계
- **생산·출력 → 잔재**: 남은 조각과 폐기
- **재단 상세**: 승인 취소
- **기준정보 → 원판 품목**: 그 원판만 걸러 보기

자동 검증은 단위 8건과 통합 4건이 돈다. 이 가이드는 자동 검증이 대신할 수 없는 것 — **숫자가 업무 감각에 맞는지, 잔재가 실제로 쓸 만한지** — 를 본다.

## 2. 검수 항목

### 2-1. 승인하면 원판 사용 실적이 남는다

1. 수주를 하나 승인하고 재단을 시작해 계산이 끝날 때까지 둔다.
2. 재단 상세에서 `승인` 을 누른다.
3. 수주 상세 `승인·생산` 탭으로 돌아간다.
4. **확인**: `재단` 영역에 `원판 사용 실적` 표가 생기고 총 장수·수율이 보인다.
5. **확인**: 표의 장수가 재단 결과의 원판 수와 같다.

**여기서 볼 것**: 손실 면적이 업무 감각에 맞는가. trim 과 자투리가 모두 손실에 들어 있다.

### 2-2. 원가와 중량이 붙는다

1. 기준정보 → 재질 → 원판 품목에서 쓰고 있는 원판에 `참고 매입원가` 를 넣는다.
2. 재질에 `밀도` 가 있어야 중량이 나온다. 없으면 중량 칸은 `—` 다.
3. 새 수주로 2-1 을 다시 한다.

- **확인**: 사용 실적에 중량과 참고 매입원가가 채워진다.
- **확인**: 원가가 비어 있는 원판을 쓴 실적은 원가만 `—` 이고 장수·면적은 그대로 나온다.

원가는 **판매가가 아니라 참고 매입원가**다(`D2-B06-D`). 수주 금액은 이 값과 무관하게 그대로다(`D2-B06-J`).

### 2-3. 기간별 실적을 본다

1. 왼쪽 메뉴 `생산·출력 → 원판 사용 실적` 을 연다.
2. **확인**: 최근 한 달이 기본으로 조회되고, 위쪽에 총계가, 아래에 원판별 합계와 재단 건별 내역이 나온다.
3. 시작일을 미래로 바꿔 조회한다.
4. **확인**: "이 기간에 승인된 재단이 없습니다." 가 나온다.

**여기서 볼 것**: 원판별 합계의 수율이 재단 상세에서 본 수율과 크게 어긋나지 않는가.

### 2-4. 기준정보에서 원판 하나만 걸러 본다

1. 기준정보 → 재질 → 원판 품목에서 `이 원판의 사용 실적 보기` 를 누른다.
2. **확인**: 사용 실적 화면이 그 원판만 걸러 열린다.
3. `원판 필터 해제` 를 누르고 다시 조회한다.
4. **확인**: 전체가 다시 보인다.

### 2-5. 잔재가 생기고 다음 재단에 쓰인다

잔재는 원판 최소 기준(`minRemnant*`)을 **모두** 넘는 조각만 생긴다(`D2-B06-C`). 기준이 비어 있으면 남는 조각이 다 잔재가 되므로, 실제 감각과 맞게 기준을 넣고 시험하는 편이 낫다.

1. `생산·출력 → 잔재` 를 연다.
2. **확인**: 2-1 에서 승인한 재단에서 나온 조각이 `남아 있음` 으로 보인다. 이름이 `R-{수주번호}-…` 라 어디서 나왔는지 읽힌다.
3. 같은 재질로 **새 수주**를 만들어 승인하고 재단을 시작한다.
4. 재단 상세의 원판 이름을 본다.
5. **확인**: 배치에 `잔재 R-…` 라는 이름의 원판이 섞여 있다면 잔재가 실제로 쓰인 것이다.
6. 그 재단을 승인하고 잔재 화면을 다시 연다.
7. **확인**: 쓴 잔재가 `사용함` 으로 바뀐다.

**여기서 볼 것 — 이번 검수의 핵심이다.** 잔재를 후보에 넣어 **원판 장수가 실제로 줄어드는가.** 줄지 않는다면 잔재를 개체로 남기는 값이 없다는 뜻이고, `D2-B06-H` 를 다시 열어야 한다.

작은 조각이 여러 개 후보로 붙어 배치가 오히려 어지러워지지 않는지도 함께 본다.

### 2-6. 실물에 없는 잔재를 폐기한다

1. 잔재 화면에서 `남아 있음` 인 조각의 `폐기` 를 누른다.
2. 사유를 넣는다. 사유 없이는 폐기되지 않는다.
3. **확인**: 상태가 `폐기` 로 바뀌고 사유가 옆에 보인다.
4. 같은 재질로 새 재단을 돌린다.
5. **확인**: 폐기한 잔재가 원판 후보에 나오지 않는다.

**여기서 볼 것**: 폐기가 충분히 쉬운가. 잔재가 실물과 어긋나는 것이 (나)의 알려진 위험이고, 지우기가 번거로우면 틀린 잔재가 쌓인다.

### 2-7. 승인을 취소하면 실적이 무효가 된다

1. 승인된 재단 상세를 연다.
2. **확인**: 승인 안내 옆에 `승인 취소` 가 있다.
3. 누르고 사유를 넣는다.
4. **확인**: 상태가 `계산 완료` 로 돌아가고 다시 계산할 수 있다.
5. 수주 상세로 간다.
6. **확인**: 사용 실적 줄이 **지워지지 않고 취소선으로** 남는다. 총계에서는 빠진다.
7. 잔재 화면을 연다.
8. **확인**: 그 재단에서 나온 잔재가 `폐기` 로 바뀌었다.
9. 그 재단이 **쓴** 잔재가 있었다면 `남아 있음` 으로 돌아와 있다.

지우지 않고 무효로 남기는 것이 `D2-B06-F` 다. 왜 사라졌는지가 남아야 한다.

### 2-8. 권한

1. `cutting.optimize` 만 있는 계정으로 들어간다.
2. **확인**: 사용 실적과 잔재를 볼 수 있다.
3. **확인**: 잔재 `폐기` 버튼과 재단 `승인 취소` 버튼이 보이지 않는다.

## 3. 알려진 것과 열린 질문

| 항목 | 내용 |
|---|---|
| 칼날 두께 | 아직 `0` 으로 계산한다(`D2-B04-K`). 실제 값이 들어오면 장수가 늘 수 있다 |
| 잔재를 쓴 줄의 원가 | `0` 으로 잡는다. 그 판값은 잔재를 만든 수주가 이미 전액 졌다(`D2-B06-I`) |
| 보유 수량 | 관리하지 않는다(`D2-B06-G` (가)). "지금 몇 장 남았는지" 는 이 화면으로 알 수 없다 |
| 잔재 위치 | 어디에 세워 뒀는지는 남기지 않는다. 이름으로만 찾는다 |
