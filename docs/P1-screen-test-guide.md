# P1 완료 화면 테스트 가이드

> 기준일: 2026-07-26
>
> 로컬 URL: `http://localhost:3000`
>
> 계정: `screen-test-admin@local.test`
>
> 비밀번호: `Browser verification phrase 2026!`

테스트 계정은 loopback 로컬 DB에서만 허용된다. 계정 복구가 필요하면 `npm run auth:ensure-local-screen-test-account`를 실행한다. 모든 확인·알림이 브라우저 기본 dialog가 아니라 서비스 공통 팝업인지 함께 확인한다.

## Windows 현장 DXF 검수

일반, 혼합 컷, 박스, 패널 파일을 현장 프로그램으로 각각 열고 다음을 기록한다.

- 열기 성공 여부와 프로그램명·버전
- 단위 mm와 1:1 치수
- 외곽 폐합, 원점과 좌표 방향
- `CUT`, `PANEL_CUT`, `V_CUT`, `A_CUT`, `BEND` 레이어 인식
- 웹 표시 치수와 현장 측정 치수의 차이

불일치는 MFC에 즉시 맞추지 말고 사례·기대값·현장 근거와 함께 P2 보정 항목으로 등록한다.
