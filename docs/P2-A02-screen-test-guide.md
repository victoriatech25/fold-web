## 2. 핵심 테스트 사례

### TC-A02-01 메뉴·목록

1. 로그인 후 왼쪽 메뉴의 `거래처·현장`을 선택한다.
2. 거래처 목록, 통합 검색, 유형, 비활성 포함, `새 거래처` 버튼을 확인한다.

기대 결과: `/customers`가 열리고 화면 폭을 넘는 가로 스크롤이 없어야 한다.

### TC-A02-02 거래처 등록·자동 코드

1. `새 거래처`에서 유형, 거래처명, 사업자등록번호, 대표자, 전화와 이메일을 입력한다.
2. `거래처 등록`을 누른다.
3. 공통 완료 팝업을 확인하고 `확인`을 누른다.

기대 결과: 상세 화면으로 이동하며 `C000001` 형식의 코드가 자동 발급된다. 고객 현장과 담당자를 입력하지 않아도 등록된다.

### TC-A02-03 기본정보 수정·중복 경고

1. 상세 화면에서 주소, 팩스, 웹사이트, 내부 비고를 추가하고 저장한다.
2. 같은 조직의 다른 거래처에 동일 사업자등록번호를 등록한다.

기대 결과: 저장 완료는 공통 팝업으로 표시된다. 중복 번호는 저장을 막지 않으며 상세 화면에 확인 경고가 표시된다.

### TC-A02-04 고객 현장 수명주기

1. 첫 고객 현장을 등록한다.
2. 두 번째 고객 현장을 등록하고 별표 버튼으로 기본 현장을 변경한다.
3. 수정 화면에서 현장 코드가 읽기 전용인지 확인한다.
4. 현장을 비활성화하고 공통 확인 팝업에서 승인한 뒤 다시 활성화한다.

기대 결과: 첫 현장은 자동 기본, 이후에는 활성 기본 현장이 최대 1개다. 현장 코드는 변경되지 않고 비활성 자료에는 상태 배지가 표시된다.

### TC-A02-05 담당자 수명주기

1. 첫 담당자를 `거래처 공통`으로 등록한다.
2. 두 번째 담당자를 특정 고객 현장에 연결한다.
3. 두 번째 담당자를 기본 담당자로 지정한다.
4. 담당자를 비활성화하고 다시 활성화한다.

기대 결과: 첫 담당자는 자동 기본이며 기본 담당자는 최대 1명이다. 담당자 카드에 연결 현장·연락처·활성 상태가 표시된다.

### TC-A02-06 통합 검색·필터

1. 목록으로 돌아가 코드, 상호 일부, 사업자번호 일부, 전화 일부를 각각 검색한다.
2. 거래처 유형을 선택해 조회한다.
3. 거래처를 비활성화한 뒤 기본 조회와 `비활성 포함` 조회를 비교한다.

기대 결과: 조건에 맞는 조직 내 자료만 나타나며 비활성 거래처는 기본 조회에서 제외되고 `비활성 포함`에서 다시 나타난다.

### TC-A02-07 공통 팝업

거래처·담당자·고객 현장의 저장, 기본 변경, 비활성화를 실행한다.

기대 결과: 브라우저 기본 `alert`, `confirm`이 나타나지 않고 모두 FOLD WEB 공통 팝업으로 처리된다.

### TC-A02-08 반응형 화면

데스크톱과 브라우저 개발자 도구의 390px 폭에서 목록·상세·등록 팝업을 확인한다.

기대 결과: 메뉴는 모바일 오버레이로 바뀌고 기본정보·담당자·현장은 단일 열로 재배치되며 가로 넘침이 없어야 한다.
