## 4. 가격 계산 검수

### `A06-CALC-01` 고객 전용 행과 상위 할증 정책

`가격 관리` 홈의 `게시 가격 미리보기`에서 다음 값을 선택한다.

| 입력 | 값 |
|---|---:|
| 거래처 | `SCREEN-PRICE · 화면검수 가격 거래처` |
| 재질·두께 | `알루미늄 · 알루미늄 1T` |
| 제품 1개 면적 | `0.3㎡` |
| 수량 | `3` |
| 제품 1개 절곡수 | `2` |
| 제품 1개 V-CUT | `1.25m` |

`가격 계산`을 누른 뒤 다음 결과를 확인한다.

| 결과 | 기대값 |
|---|---:|
| 재질비 | `15,300원` |
| 절곡비 | `4,800원` |
| V-CUT비 | `1,500원` |
| 가공 할증 | `630원` |
| 공급가액 | `22,230원` |

- 적용 출처는 `거래처 전용`이어야 한다.
- 고객 가격표에 할증 정책이 없으므로 STANDARD의 `최소 3회 미만·가공 소계 10%` 정책을 사용한다.
- 절곡수 `3`으로 바꾸면 경계값이므로 가공 할증은 `0원`, 공급가액은 `24,000원`이어야 한다.
- 결과에는 `pricing-engine-v1`, `VAT 별도`, 미리보기 비저장 성격이 드러나야 한다.

### `A06-CALC-02` 행 단위 fallback

같은 거래처에서 `알루미늄 · 알루미늄 2T`를 선택하고 나머지는 최초 값으로 되돌려 계산한다.

기대 결과:

- 고객·우대 가격표에 AL 2T 행이 없으므로 `조직 기본`을 사용한다.
- 재질비 `27,000원`, 절곡비 `7,200원`, V-CUT비 `2,250원`, 할증 `945원`, 공급가액 `37,395원`이다.
- ㎡·절곡·V-CUT 세 단가가 서로 다른 scope에서 섞이지 않는다.

## 5. 개정과 공통 팝업 검수

### `A06-REV-01` 안전하게 초안 생성·저장·반려·폐기

1. `화면검수 거래처 전용 가격표`에서 `새 개정 만들기`를 누른다.
2. 생성 완료 공통 팝업을 확인하고 닫는다. 개정 번호는 기존 폐기 이력에 따라 `r2` 이상일 수 있다.
3. 변경 요약을 `화면 검수 임시 변경`으로 바꾸고 AL 1T의 재질 단가를 `17100`으로 바꿔 `저장`한다.
4. 저장 완료 공통 팝업을 닫고 값과 checksum이 갱신되는지 확인한다.
5. `검토 요청`에서 현재 시각 이전 또는 현재 시각을 선택해 요청하고 완료 팝업을 닫는다.
6. `수정 반려`를 선택하고 사유 `화면 검수 후 원복`을 입력한다.
7. 다시 초안 상태가 되면 `폐기`를 누르고 확인 공통 팝업에서 `확인`한다.
8. 상태 변경 완료 팝업을 닫고 게시 `r1`만 남는지 확인한다.

기대 결과:

- 작성 중 개정은 동시에 한 건만 만들 수 있다.
- 게시 `r1`은 직접 수정되지 않는다.
- 검토 요청·반려·폐기는 상태와 lockVersion을 갱신한다.
- 알림·확인·사유 입력은 모두 서비스 공통 팝업이며 브라우저 시스템 팝업이 뜨지 않는다.
- 폐기 후 게시 가격 계산 결과는 `A06-CALC-01`과 동일하다.

### `A06-REV-02` 일괄 조정과 원판 가격 편집

초안을 새로 만들고 다음을 확인한 뒤 마지막에는 폐기한다.

1. 절곡 가격 표에서 한 행의 체크박스를 선택한다.
2. `일괄 조정`을 열어 대상 항목과 금액/비율을 선택하고 적용한다.
3. 선택한 행·항목만 변경되고 음수 결과는 허용되지 않는지 확인한다.
4. 원판 가격 표에 재료 판매가와 선택적 가공 판매가를 입력해 저장한다.
5. `가공 할증`을 사용으로 바꾸고 최소 절곡수·할증률을 입력해 저장한다.
6. 저장 완료 뒤 초안을 폐기해 기준 seed 상태로 돌아간다.

## 6. 오류·반응형 검수

### `A06-ERR-01` 입력 오류

- 미리보기에서 거래처나 재질을 선택하지 않고 계산하면 필수 선택 안내가 표시돼야 한다.
- 면적·V-CUT 길이에 음수나 잘못된 문자열, 수량·절곡수에 범위 밖 값을 넣으면 계산을 차단해야 한다.
- 가격표 초안에 음수 단가나 100% 초과 할증률을 저장하면 공통 오류 팝업으로 설명해야 한다.

### `A06-RWD-01` 다양한 화면 폭

브라우저 폭을 약 `390px`, `768px`, `1280px`, `1920px`로 바꿔 확인한다.

- 서비스 셸과 가격 화면이 viewport 바깥으로 전체 가로 스크롤되지 않는다.
- 작은 폭에서는 카드와 표 영역이 읽을 수 있는 순서로 쌓인다.
- 개정 이력, 저장·검토·게시 버튼과 공통 팝업을 스크롤로 접근할 수 있다.
- 가격 계산 결과의 항목명과 금액이 잘리지 않는다.
