# FOLD WEB 수동 화면 테스트 가이드

> 목적: 개발자나 검수자가 같은 환경에서 화면 테스트를 반복하고, 실패 지점을 쉽게 재현할 수 있도록 메뉴 위치·입력값·기대 결과를 고정한다.
>
> 기준 서버: `http://localhost:3001`  
> 테스트 계정: `screen-test-admin@local.test`  
> 비밀번호: `Browser verification phrase 2026!`  
> 데이터: 로컬 개발 DB 전용. 운영 DB와 운영 계정에는 사용하지 않는다.

## 1. 테스트 시작 전 준비

### 1.1 서버와 DB 확인

프로젝트 루트(`/Users/kyhoon/Work/Biz/Victoria-tech/fold_web`)에서 실행한다.

```bash
nc -z 127.0.0.1 5432
APP_ORIGIN=http://localhost:3001 PORT=3001 npm run dev -- --hostname 127.0.0.1
```

브라우저에서 `http://localhost:3001/login`을 열어 로그인 화면이 표시되는지 확인한다. 이미 서버가 실행 중이면 두 번째 명령을 다시 실행하지 않는다.

테스트 계정이 없거나 로그인되지 않으면 다음을 실행한다.

```bash
npm run auth:ensure-local-screen-test-account
```

주소 표시줄은 반드시 `localhost:3001`이어야 한다. `127.0.0.1:3001` 또는 다른 포트를 사용하면 출처 검증 오류가 발생할 수 있다.

### 1.2 로그인

1. 로그인 화면 중앙의 `이메일` 입력란에 `screen-test-admin@local.test`를 입력한다.
2. 바로 아래 `비밀번호`에 `Browser verification phrase 2026!`를 입력한다.
3. `로그인` 버튼을 누른다.
4. `/`로 이동하고 상단 제목 `업무 홈`이 보이면 성공이다.
5. 우측 상단 또는 모바일 메뉴 하단에 `로컬 화면 테스트 관리자`가 표시되는지 확인한다.

모든 저장·삭제 확인은 브라우저 기본 `alert/confirm/prompt`가 아니라 FOLD WEB 공통 팝업으로 표시되어야 한다. 팝업이 뜨면 먼저 내용을 기록하고 `확인`, `취소`, 또는 해당 작업 버튼을 눌러 닫는다.

## 2. 메뉴 위치 빠른 안내

데스크톱에서는 화면 왼쪽 고정 사이드바를 사용한다. 모바일(폭 1023px 이하)에서는 상단 왼쪽 `☰ 메뉴 열기`를 누르면 같은 메뉴가 오버레이로 열린다.

| 사이드바 구역 | 메뉴 | 주소 | 주요 검수 내용 |
|---|---|---|---|
| 업무 | 홈 | `/` | 요약 카드, 최근 초안, 기능/준비 중 구분 |
| 업무 | 도면 설계 | `/fold-editor` | 2D·3D·전개도·분할, 초안, 계산 |
| 업무 | 템플릿 | `/fold-library` | 분류·검색·검토·게시·개정·비교 |
| 업무 | 수주·작업 | `/orders` | 수주 생성·절곡 snapshot·자동 저장·복사·취소 |
| 업무 | 생산·절단 | 준비 중 | 비활성 메뉴인지 확인 |
| 업무 | 출력·이력 | 준비 중 | 비활성 메뉴인지 확인 |
| 관리 | 거래처·현장 | `/customers` | 거래처·담당자·고객 현장 |
| 관리 | 재질·두께 | `/materials` | 재질·두께·원판·계산 기준 |
| 관리 | 가격 관리 | `/pricing` | 가격표·가격 계산·개정 |
| 관리 | 회사·사업장 | `/admin/company` | 회사 정보·사업장 |
| 관리 | 조직 관리 | `/admin/users` | 사용자 초대·상태·역할 |
| 관리 | 부서 | `/admin/departments` | 부서 등록·활성 상태 |
| 관리 | 역할과 권한 | `/admin/roles` | 권한별 역할 |
| 관리 | 감사 로그 | `/admin/audit-logs` | 행위·대상·전후 값 |

현재 메뉴가 보이지 않으면 로그인한 계정의 권한이 부족한 것이다. 이 가이드는 모든 관리 권한이 있는 로컬 관리자 계정을 기준으로 한다.

## 3. 공통 테스트 규칙

각 테스트는 다음 순서로 기록한다.

1. 테스트 ID와 시작 URL을 기록한다.
2. 메뉴 이동 경로를 그대로 따라간다.
3. 입력값은 표의 값을 그대로 사용한다.
4. 저장 후 성공 팝업 문구와 상태 배지를 기록한다.
5. 기대 결과와 실제 결과를 비교한다.
6. 실패하면 화면 이름, 버튼명, 입력값, 오류 문구, 발생 시각, 스크린샷을 남긴다.

테스트용 이름에는 `화면검수`, `수동검수`, 또는 날짜를 포함하면 기존 데이터와 구분하기 쉽다. 같은 테스트를 반복할 때 이미 존재하는 코드는 새 값을 사용하거나 테스트 DB를 초기화한다.

## 4. 업무 메뉴 테스트

### 4.1 홈: 로그인과 메뉴 진입 — `HOME-01`

1. 로그인 직후 왼쪽 사이드바의 `업무 > 홈`을 확인한다.
2. `업무 홈` 제목, 최근 초안 영역, 요약 카드가 보이는지 확인한다.
3. `새 도면 설계` 링크를 눌러 `/fold-editor`로 이동한다.
4. 브라우저 뒤로 가기 또는 상단 `업무 홈으로 이동` 링크로 홈에 돌아온다.
5. `수주·작업`은 실제 기능 링크로 열리고, `생산·절단`, `출력·이력`은 회색 `준비 중` 배지와 함께 비활성인지 확인한다.

통과 기준: 실제 기능 링크와 준비 중 메뉴가 시각적으로 구분되고, 권한 없는 준비 중 메뉴를 클릭해도 페이지가 열리지 않는다.

### 4.2 도면 설계 기본 흐름 — `EDITOR-01`

1. `업무 > 도면 설계`를 누른다.
2. 상단 도구줄에서 `새 초안`을 누른다.
3. 대화상자 `새 절곡 초안`에서 이름 `수동검수 일반 도면`, 도면 타입 `일반`, 서버 재질 기준 `알루미늄 · r1`, 원판 기준은 기본값을 선택한다.
4. `생성`을 누르고 공통 완료 팝업을 닫는다.
5. 상단 초안 이름 입력란에 `수동검수 일반 도면 수정`을 입력한다.
6. 우측 또는 하단 `제품 크기 계산` 영역에서 `길이 (mm)`를 `2400`, `수량`을 `10`으로 입력한다.
7. 상단 저장 상태가 `저장됨`이 될 때까지 기다린다.
8. 브라우저를 새로고침한다.

통과 기준: 같은 초안 URL과 이름·길이·수량이 복원되고, 저장 상태가 다시 `저장됨`으로 표시된다.

### 4.3 2D 선 편집·Undo·계산 — `EDITOR-02`

1. 도면 설계 화면 상단에서 화면 모드 `절곡(2D)`를 선택한다.
2. 캔버스 도구에서 `연속 선 그리기`를 누른다.
3. 캔버스 빈 공간을 순서대로 클릭해 3개 선을 만든다. 마지막 점을 첫 점 근처에서 다시 클릭해 닫힌 형상을 시도한다.
4. 선을 클릭해 선택한 뒤 우측 속성 탭 `선 속성`을 연다.
5. 길이 입력을 `120`으로 바꾸고 캔버스의 해당 선 길이와 제품 계산 요약이 갱신되는지 확인한다.
6. 제목 또는 캔버스 영역을 한 번 클릭한 뒤 `Cmd/Ctrl+Z`, 다시 `Cmd/Ctrl+Shift+Z`를 누른다.
7. `Delete` 또는 `Backspace`로 선택 선을 삭제하고 인접 선 연결이 유지되는지 확인한다.

통과 기준: 선 선택 강조, 연결 유지, Undo/Redo, 계산 요약 즉시 반영이 모두 동작한다. `Esc`는 그리기 종료, `Space + 드래그`는 캔버스 이동이다.

### 4.4 3D·전개도·분할 동기화 — `EDITOR-03`

1. 도면 설계 화면 상단의 `3D`를 누른다. `3D 미리보기` 영역과 자기 교차 경고 여부를 확인한다.
2. 같은 화면에서 선 또는 면을 선택한다.
3. `전개도`를 누르고 `일반 절곡 전개도` 영역에서 같은 대상이 강조되는지 확인한다.
4. XL 화면이면 `분할`을 누르고 2D/3D/전개도 구분선을 드래그한다.
5. 구분선을 더블 클릭해 기본 비율로 되돌린다.

통과 기준: 화면 모드를 바꿔도 동일한 원본 선 선택이 유지되고, 캔버스가 화면 아래로 잘리지 않는다.

### 4.5 재질 기준과 수식 — `EDITOR-04`

1. 도면 설계 우측 속성 패널의 `연신율 설정`을 누른다.
2. `서버에 발행된 재질 계산 기준입니다.` 안내, `FIX 고정값`, `RATIO 비율`, `연신율 V/A/N`, `컷 제한각`, `Decimal 계산 정책`을 확인한다.
3. `변수·수식` 탭을 누르고 `변수 추가`를 두 번 누른다.
4. 변수 하나에 이름 `W`, 값 `120`을 입력하고 다른 변수에는 이름 `HALF`, 계산식 `W/2`를 입력한다.
5. `선 속성` 탭으로 돌아가 선의 `수식 입력`을 켜고 길이 수식 `W/2`를 입력한다.
6. 다시 `변수·수식` 탭에서 제품 길이 수식 사용을 켜고 `W*10`을 입력한다.
7. 계산 제품 길이가 `1200 mm`인지 확인한다.
8. 수식을 `W/0`으로 바꾸고 `0으로 나눌 수 없습니다.` 오류가 표시되는지 확인한다. 테스트 후 원래 수식으로 되돌린다.

통과 기준: 서버 발행 기준은 읽기 전용이며, 수식 계산값과 오류가 입력 가까이에 표시된다.

### 4.6 DXF 출력과 자동 저장 충돌 — `EDITOR-05`

1. 도면 설계 상단에서 `DXF 출력`을 누른다.
2. 다운로드가 시작되고 `DXF 생성 완료` 공통 팝업에 파일명·SHA-256이 표시되는지 확인한다.
3. 같은 초안 URL을 새 브라우저 탭에서 연다.
4. 두 탭에서 초안 이름이나 선 길이를 서로 다르게 변경하고 저장을 기다린다.
5. 늦게 저장한 탭에서 `다른 화면의 저장과 충돌했습니다.` 안내가 나타나는지 확인한다.
6. `서버본 다시 읽기`와 `새 초안으로 복사` 중 하나를 선택해 충돌을 해결한다.

통과 기준: DXF가 `.dxf`로 내려받아지고, 충돌 시 서버본을 덮어쓰지 않고 사용자가 선택할 수 있다.

### 4.7 템플릿 라이브러리 — `LIB-01`

1. 사이드바 `업무 > 템플릿`을 누른다.
2. 화면 왼쪽 `분류` 영역의 `분류 추가`를 누르고 `수동검수`를 등록한다.
3. 상단 검색란 `템플릿 이름 또는 코드`에 검색어를 넣고 `검색`을 누른다.
4. 템플릿 목록에서 대상을 선택한다.
5. 상세에서 이름·분류를 바꾸고 `정보 저장`을 누른다.
6. 초안 상태에서 `검토 요청` → 공통 팝업의 `검토 요청`을 누른다.
7. 검토 상태에서 `게시` → 확인 팝업의 `게시`를 누른다.
8. 게시된 개정에서 `선택 개정으로 새 초안`을 눌러 새 개정을 만든다.
9. `개정 비교` 영역에서 왼쪽·오른쪽 개정을 선택하고 `비교` 결과를 확인한다.

통과 기준: 상태가 `초안 → 검토 중 → 게시` 순서로 바뀌고, 개정 번호·변경자·변경 시각·차이 수가 표시된다.

### 4.8 수주 기본정보 — `ORDER-01`

1. 사이드바 `업무 > 수주·작업`을 눌러 `/orders`를 연다.
2. `새 수주 거래처`에서 활성 거래처를 선택하고 `새 수주`를 누른다.
3. `SO-YYYY-000001` 형식의 수주번호와 `작성 중` 상태를 확인한다.
4. 거래처·고객 현장·거래처 담당자·사내 담당자, 납기·외부 참조·내부 비고를 변경한다.
5. 1초 뒤 `저장됨`이 표시되면 새로고침해 값이 복원되는지 확인한다.
6. `복사`로 새 번호의 사본을 만들고, `취소`에서 사유를 입력한다.
7. 취소 수주가 읽기 전용인지 확인하고 목록에서 번호·거래처·상태로 다시 조회한다.

통과 기준: 번호가 중복되지 않고, 자동 저장·재접속 복원·복사·취소·검색이 동작하며 모든 확인과 사유 입력은 공통 팝업으로 표시된다. 상세 충돌·권한·반응형 검수는 [P2-A07 화면 테스트 가이드](./P2-A07-screen-test-guide.md)를 따른다.

### 4.9 수주 절곡 작업 스냅샷 — `ORDER-02`

1. 작성 중 수주 상세에서 `절곡 작업 추가`를 누른다.
2. `SCREEN-FOLD-L`을 검색하고 `화면검수 ㄱ자 절곡`을 추가한다.
3. 고객정보 고정 안내와 거래처·현장·거래처 담당자 잠금을 확인한다.
4. 수량, 직접 입력 변수 `A`, 재질·두께와 원판을 변경하고 `작업 입력 저장`을 누른다.
5. 작업을 복사하고 위·아래 순서를 바꾼 뒤 사본을 제거한다.
6. 새로고침 후 작업 입력과 순서가 복원되는지 확인한다.

통과 기준: 게시 개정이 주문 snapshot으로 독립 보존되고, 허용 입력만 바뀌며 복사·정렬·제거·재접속 복원이 동작한다. 불변성·충돌·권한·감사·390px 검수는 [P2-A08 화면 테스트 가이드](./P2-A08-screen-test-guide.md)를 따른다.

## 5. 관리 메뉴 테스트

### 5.1 거래처·현장 — `MASTER-01`

1. `관리 > 거래처·현장`을 누른다.
2. 검색 영역에 거래처 코드·상호·사업자번호·전화번호 일부를 입력해 각각 `조회`한다.
3. `새 거래처`에서 상호 `수동검수 거래처`, 사업자번호·대표자·연락처를 입력해 저장한다.
4. 생성된 거래처 카드를 눌러 상세로 이동한다.
5. 상세 하단에서 담당자를 추가하고 `기본 담당자 지정`을 누른다.
6. `고객 현장` 영역에서 현장을 추가하고 `기본 현장 지정`을 누른다.
7. 거래처를 비활성화한 뒤 목록의 `비활성 포함`을 켜서 다시 조회한다.

통과 기준: 자동 거래처 코드, 담당자·현장 연결, 기본값 단일성, 비활성 필터가 동작한다.

### 5.2 재질·두께·원판 — `MASTER-02`

1. `관리 > 재질·두께`에서 `알루미늄 AL` 카드를 누른다.
2. `새 재질`을 눌러 코드 `MANUAL-MAT`, 이름 `수동검수 재질`, 밀도 `7850`을 입력한다.
3. 상세에서 `두께 추가`를 눌러 코드 `MANUAL-MAT-12`, 표시 이름 `수동검수 1.2T`, 두께 `1.2`, 반경 `1.2`를 입력한다.
4. 저장 후 해당 두께에 `계산 기준 필요`가 표시되는지 확인한다.
5. 두께 행의 `원판 품목`을 눌러 `원판 등록`을 연다.
6. 코드 `MANUAL-SHEET-1000X2000`, 이름 `수동검수 원판`, 폭 `1000`, 길이 `2000`, 위·아래 trim `10`을 입력한다.
7. `미리 계산`을 눌러 유효 크기 `1000 × 1980mm`, 유효 면적 `1.98㎡`를 확인하고 저장한다.
8. 카드의 `기본 지정`, `비활성화`, `재활성화`를 순서대로 실행한다.
9. `관리 > 도면 설계`로 이동해 새 초안 대화상자의 `원판 기준` 목록에 활성 원판만 보이는지 확인한다.

통과 기준: 코드·두께·폭·길이의 읽기 전용 규칙, 계산 기준 필요 상태, trim 계산, 기본·비활성 수명주기가 지켜진다.

### 5.3 계산 기준 개정 — `MASTER-03`

1. `재질·두께 > 알루미늄 AL > 계산 기준`을 누른다.
2. 현재 적용 개정의 `새 개정 만들기`를 누른다.
3. 계산 방식·연신 적용 옵션·V-CUT·FIX/RATIO 값을 확인하고 변경 요약 `수동검수 개정`을 입력한다.
4. `초안 저장`을 누른다.
5. 새 개정의 `미리보기`를 눌러 134°·135°·136° 경계 표본을 확인한다.
6. `검토 요청` 후 `게시`한다.
7. 게시 후 현재 적용 개정 번호와 이전 개정 종료 상태를 확인한다.
8. 테스트 개정이 운영 기준처럼 남지 않도록 필요한 경우 새 개정을 `예약 취소` 또는 폐기한다.

통과 기준: 게시본은 직접 수정되지 않고 새 개정으로만 변경되며, 검토·게시·예약 상태와 처리 이력이 남는다.

### 5.4 가격 관리 — `MASTER-04`

1. `관리 > 가격 관리`를 누른다.
2. 요약 카드에서 활성 가격등급·사용 중 가격표·가격 대상 거래처를 확인한다.
3. `게시 가격 미리보기`에서 거래처 `SCREEN-PRICE · 화면검수 가격 거래처`, 재질 `알루미늄 · 알루미늄 1T`, 면적 `0.3㎡`, 수량 `3`, 절곡수 `2`, V-CUT `1.25m`를 입력한다.
4. `가격 계산`을 누르고 공급가액 `22,230원`과 적용 출처 `거래처 전용`을 확인한다.
5. `화면검수 거래처 전용 가격표`를 열어 `r1 사용 중`과 단가·checksum을 확인한다.
6. `새 개정 만들기` → 변경 → `폐기`를 실행하고 공통 확인 팝업을 확인한다.

통과 기준: 고객 전용 가격 우선순위, 상위 가격표 fallback, 할증 계산, 개정 폐기가 모두 표시된다. 가격은 `LOCAL TEST ONLY`, VAT 별도 자료다.

### 5.5 회사·사업장 — `ADMIN-01`

1. `관리 > 회사·사업장`을 누른다.
2. `회사 기본정보`에서 회사명·대표자·연락처를 확인하고 `회사정보 저장`을 누른다.
3. `사업장` 영역에서 `사업장 추가`를 누르고 `수동검수 사업장`을 등록한다.
4. 카드의 `기본 지정`을 누르고 확인 팝업의 `기본 지정`을 누른다.
5. 두 번째 사업장을 추가해 기본값을 바꾼다.
6. 한 사업장을 `비활성화`한 뒤 `비활성 포함` 필터로 다시 확인한다.

통과 기준: 기본 사업장은 항상 최대 1개이며, 비활성 사업장은 새 업무 선택에서 제외된다.

### 5.6 조직 관리·부서·역할 — `ADMIN-02`

1. `관리 > 조직 관리`에서 `초대 주소 발급`을 누른다.
2. 표시 이름 `수동검수 조회자`, 역할 `조회자`를 입력해 초대 주소를 만든다.
3. `관리 > 부서`에서 `부서 추가`로 `수동검수 부서`를 등록한다.
4. `관리 > 역할과 권한`에서 사용자 정의 역할을 추가하고 필요한 조회 권한을 체크한다.
5. 조직 관리 목록에서 테스트 사용자의 역할을 확인한다.
6. 조회자 세션으로 관리 URL(`/admin/users`)을 열어 접근 거부 또는 메뉴 숨김을 확인한다.

통과 기준: 초대 주소, 역할·권한, 부서 연결이 저장되고 권한 없는 사용자는 관리 기능을 사용할 수 없다.

### 5.7 감사 로그 — `ADMIN-03`

1. 위 관리 테스트 중 회사 저장, 거래처 저장, 재질 등록, 가격표 폐기 중 하나를 실행한다.
2. `관리 > 감사 로그`를 연다.
3. 기간·행위자·대상 필터를 사용해 방금 실행한 이벤트를 찾는다.
4. 이벤트 상세에서 행위자, 대상, 전 값, 후 값, 시각을 확인한다.

통과 기준: 변경 작업마다 조직 범위의 감사 이벤트가 생성되고, 민감한 값은 평문으로 노출되지 않는다.

## 6. 반응형 테스트 — `RESP-01`

브라우저 개발자 도구 또는 Playwright viewport로 다음 폭을 차례로 확인한다: `390×844`, `768×1024`, `1440×900`, `1920×1080`.

각 폭에서 다음을 반복한다.

1. 로그인 화면과 `업무 홈`을 새로고침한다.
2. 모바일 폭이면 `☰ 메뉴 열기` → 메뉴 선택 → 메뉴가 자동으로 닫히는지 확인한다.
3. 도면 설계에서 `2D`, `3D`, `전개도`, `분할`을 차례로 연다.
4. 관리 메뉴 하나의 목록·상세·등록 대화상자를 연다.
5. `document.documentElement.scrollWidth`가 화면 clientWidth보다 크지 않은지 확인한다.

통과 기준: 가로 스크롤이 없고, 대화상자 본문은 세로 스크롤되며, 하단 저장·취소 버튼이 화면 밖으로 밀리지 않는다.

## 8. 자동 검증과 수동 검수의 구분

수동 화면 검수 전후에 다음 명령으로 회귀 여부를 확인한다.

```bash
npm test
npm run test:integration
npm run test:e2e
npm run lint
npm run typecheck
```

자동 테스트가 통과해도 메뉴 위치·문구·팝업·반응형 배치는 수동으로 확인해야 한다. 반대로 수동 테스트가 통과해도 계산·권한·DB 동시성은 자동 테스트 결과를 함께 기록한다.

## 9. 문제 해결

| 증상 | 확인할 것 | 조치 |
|---|---|---|
| 로그인 출처 오류 | 주소가 `localhost:3001`인지 | `http://localhost:3001/login`을 새로 연다 |
| 로그인 계정 없음 | 로컬 DB와 계정 상태 | `npm run auth:ensure-local-screen-test-account` |
| 메뉴가 없음 | 역할 권한 | 관리자 계정으로 다시 로그인 |
| 저장이 계속 대기 | 서버·PostgreSQL 포트 | `nc -z 127.0.0.1 5432`, 서버 터미널 확인 |
| 다른 탭 충돌 | 두 탭의 초안 URL이 같은지 | 서버본 다시 읽기 또는 새 초안으로 복사 |
| 데이터가 너무 많음 | 이전 수동 테스트 잔여 데이터 | 테스트 이름·코드를 새로 사용하거나 로컬 테스트 DB 초기화 후 seed |
| 3000 포트 접속 | 다른 프로젝트와 충돌 | 이 프로젝트 기준 주소는 `localhost:3001` |

관련 기능별 상세 기준은 [P1 화면 테스트 가이드](./P1-screen-test-guide.md), [P2-A01](./P2-A01-screen-test-guide.md)부터 [P2-A07](./P2-A07-screen-test-guide.md)를 함께 참고한다.
