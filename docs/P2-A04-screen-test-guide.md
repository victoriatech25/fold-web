## 3. 추가 확인 사항

- 한 두께에는 `초안` 또는 `검토 중`인 진행 개정이 합계 한 건만 존재한다.
- 게시본의 계산 내용은 직접 수정할 수 없고 `새 개정 만들기`로만 변경한다.
- FIX/RATIO의 여섯 값은 현재 계산 방식과 관계없이 함께 보존된다.
- 모든 성공·오류·확인·사유 입력은 공통 팝업으로 표시되며 브라우저 native `alert`, `confirm`, `prompt`를 사용하지 않는다.
- 이미 저장된 도면은 당시 규칙 snapshot을 유지하며, 새 선택이나 재질 재적용 때 현재 게시 개정을 사용한다.
