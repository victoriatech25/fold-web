# P2-A11 수주 목록·이력 화면 테스트 가이드

> 상태: `READY_FOR_USER_VERIFY` (2026-08-17)
>
> 담당자·검수자: 사용자 본인
>
> 테스트 주소: `http://localhost:3001`
>
> 포트 안내: 이 문서를 쓸 당시 검수 서버는 `3001` 이었다. 지금은 `npm run dev` 가 `8000` 을 고정하므로 아래 주소의 `3001` 을 `8000` 으로 읽는다.
>

## 1. 접속 준비

| 항목 | 값 |
|---|---|
| 로그인 | `http://localhost:3001/login` |
| 이메일 | `screen-test-admin@local.test` |
| 비밀번호 | `Browser verification phrase 2026!` |
| 거래처 | `SCREEN-PRICE · 화면검수 가격 거래처` |
| 템플릿 | `SCREEN-FOLD-L · 화면검수 ㄱ자 절곡` |

기존 A09·A10 검수 수주를 재사용하거나 새 수주를 2건 이상 만든다. 상태별 검색을 확인하려면 작성 중 수주와 계산 완료/승인/생산 요청 수주을 각각 하나씩 준비한다.

## 2. 수주 목록 검색

### `A11-LIST-01` 검색어·거래처·담당자

1. `업무 > 수주·작업`으로 이동한다.
2. 수주 검색에 수주번호 일부 또는 `SCREEN-PRICE`를 입력하고 조회한다.
3. 거래처 필터로 `SCREEN-PRICE`를 선택해 조회한다.
4. 담당자 필터를 선택해 조회한다.

기대 결과: 모든 조건은 AND로 결합되며 목록에는 수주번호, 거래처, 수주일, 납기, 담당자, 상태가 표시된다. 승인 수주는 `승인 총액`도 표시된다.

### `A11-LIST-02` 기간·복수 상태

1. 수주일 시작·종료일을 입력한다.
2. 수주 상태 목록에서 macOS는 `⌘`, Windows는 `Ctrl`을 누른 채 `작성 중`, `계산 완료` 등 둘 이상을 선택한다.
3. 조회한다.

기대 결과: 기간 밖 수주나 선택하지 않은 상태는 목록에서 제외된다. 상태를 선택하지 않으면 전체 상태를 조회한다.

### `A11-LIST-03` 빈·더 보기 상태

- 존재하지 않는 검색어를 넣으면 빈 상태와 다음 행동을 확인한다.
- 25건을 넘는 결과가 있는 조직에서는 `수주 더 보기`를 눌러 중복 없이 다음 페이지가 이어지는지 확인한다.

## 3. 수주 이력

### `A11-HISTORY-01` 변경·계산·승인 이력

1. 절곡 작업·계산·승인 또는 생산 상태 이력이 있는 수주를 연다.
2. 상세 하단 `수주 이력`을 확인한다.

기대 결과: 수주 생성/변경, 절곡 작업, 계산·가격 snapshot, 승인·생산 상태 전이가 최신순으로 표시되고, 행위자·시각·결과가 보인다. 계산 전체 JSON, 절곡 작업 문서, 원시 감사 payload는 표시되지 않아야 한다.

### `A11-HISTORY-02` 상태 전이 직후 갱신

1. 계산 완료 수주에서 승인 또는 승인 수주에서 생산 요청을 실행한다.
2. 페이지를 새로고침하지 않고 `수주 이력`을 확인한다.

기대 결과: 새 상태 전이가 즉시 목록 최상단에 나타난다.

## 4. 생산 요청 진입

### `A11-PRODUCTION-01`

1. 목록에서 `승인` 상태 수주를 연다.
2. 상세의 `생산 요청`을 실행한다.

기대 결과: 상태가 `생산 요청`으로 바뀌고 목록 검색에서 해당 상태로 찾을 수 있다. 승인 계산·입력은 계속 읽기 전용이며 수주 이력에 전이가 남는다.

## 5. 권한·반응형

### `A11-PERMISSION-01`

- `order.read`만 있는 사용자는 목록·필터·이력을 읽을 수 있지만 새 수주·상태 전이 버튼은 없어야 한다.
- 다른 조직 수주 ID는 목록·상세·이력 모두 접근할 수 없어야 한다.
- 전역 감사 로그의 원시 payload는 `audit.read`가 없으면 볼 수 없어야 한다.

### `A11-RWD-01`

브라우저 폭 `390px`, `768px`, `1280px`, `1920px`에서 목록과 수주 이력을 확인한다.

- 전체 viewport 가로 스크롤이 없어야 한다.
- 필터는 좁은 화면에서 자연스럽게 세로로 쌓여야 한다.
- 상태 복수 선택과 `수주 더 보기`, `이력 더 보기` 버튼에 접근할 수 있어야 한다.
- 긴 수주번호·담당자명·상태 이력이 카드 폭을 넘기지 않아야 한다.
