# P2-B11 그룹재단 화면 테스트 가이드

> 대상: [P2-B11 상세계획](./work-items/P2-B11-group-cutting.md)
>
> 작성일: 2026-09-12
>
> 검수자: 사용자 본인
>
> 검수 결과: 미검수

MFC 의 `그룹재단` — 재단 결과를 한 화면에서 손으로 편집하고 원판마다 장비용 DXF 를 내는 기능 — 을 웹에 올린 것이다. 사용자가 2026-09-12 에 확인한 정의를 따른다.

- **재단 상세(`/cutting/{id}`)**: `배치 편집` 진입, 개정 이력의 `출처`(계산/편집), 그룹·절단선·필름 표시, `원판 DXF` 패널
- **재단 편집(`/cutting/{id}/edit`)**: 도구 모드 셋(부품 이동·레이저 그룹·절단선), 원판 추가·삭제, 미배치 부품, 실행취소, 검증 상태, 저장

자동 검증은 단위 22건(편집 상태·검증·DXF 조립·zip)·통합 4건·E2E 1건이 돈다. 이 가이드는 자동 검증이 대신할 수 없는 것 — **편집이 현장 감각대로 움직이는지, DXF 가 장비에서 읽히는지** — 를 본다.

## 1. 준비

터미널 셋을 띄운다.

```bash
docker compose up -d storage
```

```bash
npm run dev
```

```bash
npm run worker
```

- 웹은 `http://localhost:8000`
- **`worker` 를 띄우지 않으면 재단 계산과 DXF 생성이 큐에 쌓인 채 끝나지 않는다.** `계산 중`·`생성 중…` 이 오래가면 worker 부터 본다
- 이번 작업은 스키마를 바꿨다(개정 컬럼 넷, `FileAsset.cuttingPlanRevisionId`, `CuttingDxfSequence`). 화면을 열기 전에 개발 DB 에 올린다

```bash
npm run db:migrate:deploy
```

- 로컬처럼 앱 계정(`fold_web_app`)과 마이그레이션 계정이 나뉜 DB 면 새 표에 권한을 준다. 없으면 DXF 생성이 `permission denied` 로 실패한다

```sql
GRANT SELECT, INSERT, UPDATE, DELETE ON "CuttingDxfSequence" TO fold_web_app;
```

- 편집할 재단이 필요하다. `P2-B06` 가이드 2-1 의 1~7 대로 승인된 수주에서 `재단 시작` 을 걸어 `계산 완료` 까지 간 재단 하나를 준비한다. **승인된 재단은 편집할 수 없으므로** 승인 전이거나 `승인 취소` 한 것이어야 한다. 부품이 같은 종류로 2장 이상 있어야 레이저 그룹을 볼 수 있다 — 절곡 작업 수량을 2 이상으로

## 2. 검수 항목

### 2-1. 편집기에 들어가 부품을 옮긴다

1. 재단 상세(`/cutting/{id}`)에서 **`배치 편집`** 을 누른다
2. **확인**: `/cutting/{id}/edit` 로 열리고 위에 도구 막대(`부품 이동`·`레이저 그룹`·`절단선` · 새 원판 · `원판 추가` · `실행취소`·`다시실행` · 검증 상태 · `취소`·`저장`)가 있다. 오른쪽에 `미배치 부품`·`검증` 카드가 있다
3. **확인**: 처음 상태는 `저장 가능` 이고 검증 카드에 `문제가 없습니다` 가 보인다 (solver 결과 그대로이므로)
4. `부품 이동` 모드에서 부품 하나를 끌어 빈 곳에 놓는다
5. **확인**: 끄는 동안 반투명 자리(고스트)가 따라오고, 놓을 수 있는 곳은 청록, 겹치거나 밖이면 빨강이다. 빨간 자리에서 놓으면 원래 자리에 남는다
6. **확인**: 이웃 부품 변에 가까이 가면 칼날 두께만큼 띄운 자리에 **붙는다**(스냅). 원판 사용 영역 변에도 붙는다
7. **확인**: 놓으면 `실행취소` 가 켜지고, 잠시 뒤 검증 상태가 다시 `저장 가능` 이 된다
8. 부품을 클릭해 선택한 뒤 **`R`** 을 누른다
9. **확인**: 그 자리에서 90° 돈다. 돌린 결과가 원판 밖으로 나가면 빨갛게 표시되고 검증 상태가 `저장 불가 1건`, 오른쪽 검증 카드에 `사용 영역 이탈 · 원판 N` 이 뜬다. `저장` 버튼이 잠긴다. **같은 부품이 여러 장이어도 문제인 장만 빨갛다**
10. `실행취소` 로 되돌린다. **확인**: 빨간 표시와 `저장 불가` 가 사라진다
11. 선택한 부품에서 **`Delete`** 를 누른다. **확인**: 원판에서 빠지고 `미배치 부품` 카드의 수량이 1 늘어난다. 검증 카드에는 미배치가 있어도 거부가 아니다 (승인 때 막힌다)
12. `미배치 부품` 의 항목을 눌러 원판 위로 끌어 놓는다. **확인**: 들고 있는 동안 `R` 로 방향이 바뀌고, 놓으면 수량이 `완료` 로 돌아온다

### 2-2. 원판을 더하고 사이로 옮기고 빈 원판을 지운다

1. 도구 막대의 `새 원판` 에서 규격을 고르고 **`원판 추가`** 를 누른다
2. **확인**: 맨 아래에 빈 `원판 N` 이 붙는다. 목록에는 이 재단의 **입력 스냅샷에 있던 규격만** 나온다(`D2-B05-D`)
3. 위 원판의 부품을 끌어 새 원판에 놓는다
4. **확인**: 원판 사이로 옮겨지고 양쪽 머리글의 `부품 N개` 가 바뀐다
5. 부품을 다시 위로 옮겨 새 원판을 비운 뒤 그 원판의 **`빈 원판 삭제`** 를 누른다
6. **확인**: 지워진다. 부품이 있는 원판과 마지막 한 장에는 이 버튼이 없다
7. **확인**: 원판을 지운 뒤에도 남은 원판의 그룹·절단선 표시가 그대로다 (원판 번호가 당겨져도 지정이 따라온다)

### 2-3. 레이저 그룹을 묶고 푼다

1. 같은 부품이 나란히(격자로) 놓인 곳을 찾는다. 없으면 부품 이동으로 두 장을 붙여 놓는다
2. **`레이저 그룹`** 모드로 바꾼다. **확인**: 원판 위 커서가 바뀌고 아래 안내가 "같은 부품이 격자로 놓인 곳을 사각형으로 골라 묶습니다" 로 바뀐다
3. 두 부품에 걸치게 사각형을 끌어 놓는다 (부품 안에서 시작해도 된다)
4. **확인**: 놓는 즉시 보라색 점선 사각형이 두 부품을 감싸고 머리글에 `레이저 그룹 1` 이 는다
5. 다른 종류의 부품까지 걸치게 골라 본다. **확인**: 묶이지 않고 위에 노란 안내 "같은 부품을 같은 방향으로 놓은 것만 묶을 수 있습니다" 가 뜬다
6. 격자가 아닌 세 장(ㄱ자)을 골라 본다. **확인**: "행×열 격자로 놓인 부품만" 안내로 거부된다
7. 묶인 그룹을 누른다. **확인**: 풀린다
8. 다시 묶은 뒤 `부품 이동` 모드에서 그룹 안 부품 하나를 옮긴다. **확인**: 옮긴 순간 그룹이 사라진다 (배치가 바뀐 그룹은 뜻을 잃는다)
9. `실행취소` 두 번. **확인**: 부품과 그룹이 함께 돌아온다

### 2-4. 절단선과 필름

1. **`절단선`** 모드에서 부품이 없는 빈 곳을 누른다
2. **확인**: 빨간 점선이 원판 폭을 가로질러 생긴다. **긴 쪽을 가로로 그리는 화면에서는 세로선으로 보인다** — 이것이 맞다. 절단선은 "길이 방향의 어느 위치에서 폭 전체를 자른다" 는 뜻이다(`D2-B05-L`)
3. 부품 한가운데를 누른다. **확인**: 놓이지 않고 "절단선이 부품을 가로지릅니다" 안내
4. 선을 누른다. **확인**: 지워진다
5. 원판 머리글의 **`필름`** 체크박스를 켠다. **확인**: 켜지고 `실행취소` 로 되돌릴 수 있다
6. 그룹·절단선·필름을 둔 채 **`저장`** 을 누른다
7. **확인**: 재단 상세로 돌아오고 개정이 하나 늘었다. 개정 이력의 `출처` 가 `편집` 이다
8. **확인**: 상세의 원판 그림에 보라 점선(그룹)·빨간 점선(절단선)·머리글 `필름` 배지가 그대로 보인다
9. 다시 `배치 편집` 으로 들어간다. **확인**: 저장한 그룹·절단선·필름이 편집기에 그대로 실려 있다

### 2-5. 경고와 함께 저장한다

1. 편집기에서 부품을 옮겨 **직선 관통으로 자를 수 없는** 배치를 만든다. 가장 쉬운 것은 풍차 모양 — 부품 넷을 서로 어긋나게 둘러 놓는다. 부품이 둘뿐이면 한 장을 다른 장의 옆에 반쯤 어긋나게 놓아도 된다
2. **확인**: 검증 상태가 `경고 N건`(노랑)이고 `저장` 은 **잠기지 않는다**. 검증 카드에 `직선 관통 불가 · 원판 N` 이 노란 글씨로 보인다(`D2-B11-G`)
3. `저장` 을 누른다. **확인**: "경고와 함께 저장" 팝업이 뜨고 건수를 말한다. 저장한다
4. **확인**: 상세의 개정 이력에서 그 개정의 `출처` 열에 `경고 N` 배지가 붙는다
5. 이 개정을 `승인` 해 본다. **확인**: 승인된다 (경고는 막지 않는다). 확인 뒤 `승인 취소` 로 되돌린다

### 2-6. 저장이 막히는 경우와 동시 편집

1. 부품 두 장을 겹쳐 놓는다 (스냅이 붙이려 하면 빠르게 놓는다. 겹치면 빨간 자리라 놓이지 않을 것이다 — 이 경우 **놓이지 않는 것 자체가 확인**이다)
2. 탭을 하나 더 열어 같은 재단 상세에서 `다시 계산` 을 누른다
3. 원래 탭의 편집기에서 `저장` 을 누른다. **확인**: "재단 작업이 다른 화면에서 변경되었습니다" 오류가 뜨고 저장되지 않는다
4. 편집기의 `취소` 를 누른다. **확인**: 바뀐 것이 있으면 "저장하지 않은 변경이 사라집니다" 팝업이 먼저 뜬다

### 2-7. 원판 DXF 를 만들고 내려받는다

1. 재단 상세에서 편집 개정(그룹·절단선·필름이 있는 것)이 현재 개정인 상태로 **`원판 DXF`** 패널의 **`DXF 생성`** 을 누른다
2. **확인**: 버튼이 `생성 중…` 이 되고, worker 가 끝내면 목록이 나타난다 — 원판마다 `{yymmdd}-{순번}-{A,B,…}.dxf`, 필름 원판은 `F` 접두, 레이저 그룹마다 `…-A-1.dxf`, 마지막에 zip
3. **확인**: 순번은 같은 날 만든 것마다 1씩 오른다. 다른 재단에서 한 번 더 만들어 보면 `-02-` 가 된다
4. 원판 파일의 **`내려받기`** 를 누른다. **확인**: 새 탭에서 받아진다
5. 받은 파일을 CAD 뷰어(또는 메모장)로 연다. **확인**: 레이어가 다음과 같다
   - `-b-{두께}-{재질코드}` 원판 외곽 사각형
   - `-L-`/`-X-` 부품 세로/가로 절단선. 필름 원판은 `-L1-`/`-X1-`
   - `- -` 레이저 그룹 **안쪽** 선 (두 부품 사이 경계). 그룹 외곽은 `-L-`/`-X-` 로 남아 있다
   - `-V-{깊이×100}` 부품 안 V-cut 선 (V-cut 이 있는 절곡일 때)
   - 이웃 부품과 맞닿은 절단선은 한 줄로 합쳐져 있다
6. **확인**: 좌표가 mm 이고 원점이 원판 왼쪽 아래, x 가 폭, y 가 길이다. 부품 사각형이 화면 배치와 같은 자리다 (화면은 긴 쪽을 가로로 눕혀 보이므로 축이 바뀌어 보일 수 있다)
7. 레이저 그룹 파일을 연다. **확인**: 그룹 첫 부품의 전개도 한 장이다 (기존 절곡 DXF 출력과 같은 레이어)
8. zip 을 받아 푼다. **확인**: 위 파일이 전부 들어 있다
9. `DXF 생성` 을 다시 누른다. **확인**: 새로 만들지 않고 같은 목록이 유지된다 (같은 개정은 한 번만)
10. **작업 큐**(`/jobs`)에서 `재단 DXF 생성` 작업이 `완료` 로 남아 있는지 본다

### 2-8. MFC 실제 DXF 와 대조 — 파일이 확보되면

MFC 로 낸 실제 DXF 파일(원판 파일 + 그룹 파일)이 있어야 하는 항목이다. 파일이 없으면 **미검수로 남긴다.**

1. MFC 파일과 웹 파일을 같은 뷰어로 나란히 연다
2. **확인**: 원점·축 방향이 같다. 다르면 4.11 의 `nBaseDraw` 회전 옵션을 연다
3. **확인**: 레이어 이름 형식이 같다 — 특히 `{색상}` 자리의 문자열, `-V-` 뒤 숫자의 의미(깊이×100), `-V1-` 의 용도
4. **확인**: 원판 외곽 사각형이 trim 을 포함한 전체인지 사용 영역인지
5. **확인**: 레이저 그룹 경계선이 MFC 에서 절단선인지 `- -` 인지
6. **확인**: 필름 파일명의 `F` 위치와 그룹 파일에도 붙는지
7. 차이를 [P2-B11 4.11](./work-items/P2-B11-group-cutting.md) 표에 적고, 코드 수정은 그 뒤에 한다

### 2-9. 권한

1. **시스템 → 역할과 권한**(`/admin/roles`)에서 테스트용 역할에 **`cutting.optimize`** 만 두고 `output.print` 는 뺀다
2. 그 역할의 계정으로 로그인한다
3. **확인**: `배치 편집`·`DXF 생성` 은 되지만 `내려받기` 를 누르면 실패한다 (DXF 파일 내려받기는 `output.print`)
4. **확인**: `cutting.optimize` 가 없는 계정은 `/cutting/{id}/edit` 에 직접 들어가도 상세로 되돌려진다
5. 역할·권한을 원상복구한다

## 3. 알려진 것과 열린 질문

| 항목 | 내용 |
|---|---|
| 실제 MFC DXF 대조 | 아직 못 했다. 레이어·좌표·파일명은 소스에서 읽은 규칙과 가정(4.11) 위에 있다. 2-8 이 그 대조다 |
| 절단선의 방향 | 화면에서 세로로 보인다. 긴 쪽을 가로로 눕혀 그리기 때문이며 뜻은 "길이 방향 위치" 다. 헷갈리면 이름을 바꾸는 것을 검토한다 |
| 재실행 뒤 지정 | 고정 후 `다시 계산` 하면 새 solver 개정에는 그룹·절단선·필름이 넘어오지 않는다(`D2-B11-C`). 다시 지정해야 한다 |
| 잔재 사각형 | 편집 개정은 잔재 사각형을 그리지 않는다. 손실 면적은 `P2-B06` 실적에 그대로 잡힌다 |
| 위반 표시 | 부품 단위 위반(수량 불일치 등)은 특정 장을 가리키지 않아 원판 그림에 빨간 표시가 없고 검증 카드에만 나온다 |
| 모바일 | 편집기는 드래그 중심이라 좁은 화면 배치를 다듬지 않았다. 상세 화면은 기존과 같다 |
