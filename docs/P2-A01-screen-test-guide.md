# P2-A01 회사·사업장 화면 테스트 가이드

> 작성일: 2026-07-26
>
> 대상: P2-A01 사용자 직접 검수
>
> 테스트 주소: `http://localhost:3000/admin/company`
>
> 계정: [로컬 화면 테스트 계정](./local-screen-test-account.md)

## 1. 확인 범위

- 회사 기본정보의 PostgreSQL 저장과 새로고침 복원
- 복수 사업장 생성·수정·검색·비활성화
- 활성 기본 사업장이 항상 하나만 유지되는지 확인
- 확인·완료·오류 안내가 모두 공통 팝업으로 표시되는지 확인
- 데스크톱과 모바일 폭에서 가로 넘침이 없는지 확인
- 변경 내역이 감사 로그에 남는지 확인

## 2. 사전 준비

1. `http://localhost:3000`에 접속한다.
2. 로컬 화면 테스트 관리자로 로그인한다.
3. 상단 `기준정보` 또는 `조직 관리 → 회사·사업장`으로 이동한다.
4. 실제 회사정보가 입력돼 있다면 변경 전 값을 따로 기록하고 테스트 후 복원한다.

## 3. 테스트 사례

### TC-A01-01 회사정보 저장

1. 회사명은 유지하고 전화번호 또는 주소에 테스트 값을 입력한다.
2. `회사정보 저장`을 누른다.
3. 시스템 팝업이 아니라 `저장 완료` 공통 팝업이 표시되는지 확인한다.
4. 페이지를 새로고침하고 입력값이 유지되는지 확인한다.

기대 결과: PostgreSQL 저장값이 복원되고 감사 로그에 `회사 정보 변경`이 기록된다.

### TC-A01-02 사업장 추가

1. `사업장 추가`를 누른다.
2. 코드 `SCREEN-SITE`, 사업장명 `화면 검수 사업장`, 유형 `공장`을 입력한다.
3. 전화번호와 주소는 비식별 테스트 값만 입력하고 저장한다.

기대 결과: 공통 편집 팝업으로 생성되며 목록에 `SCREEN-SITE`가 표시된다. 코드는 대문자로 저장된다.

### TC-A01-03 기본 사업장 변경

1. `화면 검수 사업장`의 `기본 지정`을 누른다.
2. 공통 확인 팝업에서 `기본으로 지정`을 누른다.

기대 결과: 새 사업장에만 `기본 사업장` badge가 표시되고 기존 본사에서는 badge가 제거된다.

### TC-A01-04 기본 사업장 보호와 비활성화

1. 현재 기본 사업장의 `수정`을 연다.
2. `사용 중`이 해제되지 않도록 비활성화돼 있는지 확인하고 닫는다.
3. 기본 사업장이 아닌 기존 본사의 `수정`을 열어 `사용 중`을 해제한다.
4. `저장` 후 공통 확인 팝업에서 `비활성화`를 누른다.

기대 결과: 기본 사업장은 직접 비활성화할 수 없고, 비기본 사업장은 확인 후 비활성화된다.

### TC-A01-05 검색·비활성 표시

1. `비활성 포함`을 선택한다.
2. 사업장 검색에 코드 또는 이름 일부를 입력한다.

기대 결과: 조건에 맞는 행만 보이며 비활성 사업장에는 `비활성` badge가 표시된다.

### TC-A01-06 새로고침·감사

1. 페이지를 새로고침하고 기본 사업장과 활성 상태가 유지되는지 확인한다.
2. `감사 로그`에서 회사 변경, 사업장 생성·변경, 기본 사업장 변경을 조회한다.

기대 결과: 행위자·대상·시각과 전후 값이 기록된다.

### TC-A01-07 반응형

1. 브라우저 폭을 데스크톱, 태블릿, 모바일 수준으로 변경한다.
2. 회사 입력, 사업장 검색·버튼·목록과 편집 팝업을 확인한다.

기대 결과: 가로 스크롤 없이 한 열 또는 두 열로 재배치되고 팝업의 저장·취소 버튼을 사용할 수 있다.

## 4. 검수 후 정리

- 회사정보를 테스트 전 값으로 복원한다.
- `화면 검수 사업장`을 기본으로 사용하지 않을 경우 본사를 다시 기본으로 지정한 다음 검수 사업장을 비활성화한다.
- 차이가 있으면 화면, 입력값, 기대 결과와 실제 결과를 기록한다.
