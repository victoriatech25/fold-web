# P2-B05 재단 작업·수동 편집 화면 테스트 가이드

> 대상: [P2-B05 상세계획](./work-items/P2-B05-cutting-plan-editing.md)
>
> 작성일: 2026-08-23
>
> 검수자: 사용자 본인
>
> 검수 결과: **2026-08-29 전체 승인.** 2-4 의 업무 판단은 고정 방식으로 충분하다는 결론이라 `D2-B05-J` 를 (가)로 확정했다. 검수 중 배치 그림 방향을 고쳤다(`D2-B05-L`)

재단이 처음으로 화면에 나오는 단계다. 콘솔에서 API를 부르지 않고 화면에서만 확인한다.

- **수주 상세 `승인·생산` 탭**: 재단 시작과 진행 확인
- **생산·출력 → 생산·절단**: 재단 목록
- **재단 상세**: 원판별 배치, 고정 후 다시 계산, 승인

계약 검증은 [`e2e/cutting.spec.ts`](../e2e/cutting.spec.ts)와 통합 테스트 5건이 자동으로 돈다. 이 가이드는 자동 검증이 대신할 수 없는 것 — **배치 그림이 실제로 읽히는지, 고정이 업무 감각에 맞는지** — 에 집중한다.

## 1. 준비

터미널 세 개를 쓴다.

```bash
docker compose up -d storage
```

```bash
npm run dev
```

```bash
npm run worker
```

- 웹: `http://localhost:8000`
- 계정 정보는 [로컬 화면 테스트 계정](./local-screen-test-account.md)에 있다

**worker 는 코드를 바꿔도 스스로 다시 읽지 않는다.** 기동 로그의 `types` 에 `cutting.optimize` 가 있어야 한다.

```json
{"event":"worker_started","types":["cutting.optimize","dxf.export","storage.cleanup"],...}
```

## 2. 검수 항목

### 2-1. 승인 전에는 재단을 열 수 없다

1. 수주를 하나 만들고 절곡 작업을 넣는다. 계산까지만 한다.
2. `승인·생산` 탭을 연다.
3. **확인**: `재단` 영역에 "수주를 승인하면 재단을 시작할 수 있습니다." 가 보이고 시작 버튼이 없다.

### 2-2. 재단을 시작하면 재질별로 작업이 생긴다

1. 같은 수주를 승인한다.
2. `승인·생산` 탭에서 `재단 시작` 을 누른다.
3. **확인**: 재질 수만큼 줄이 생기고 상태가 `계산 중` 이다.
4. **확인**: 몇 초 안에 `계산 완료` 로 바뀌고 원판 수·수율이 채워진다. 새로고침하지 않아도 바뀐다.

재질이 둘 이상인 수주로도 한 번 해 본다. 원판이 재질에 매여 있어 작업이 나뉜다.

### 2-3. 배치 그림이 읽히는가

1. `결과 보기` 로 재단 상세를 연다.
2. **확인**: 원판마다 그림이 하나씩 있고, 부품 사각형에 작업 이름이 적혀 있다.
3. **확인**: 잔재는 점선으로 구분된다.
4. **확인**: 원판의 긴 쪽이 화면에서 **가로**로 놓이고, 부품이 **좌상단**부터 채워져 보인다.

**여기서 볼 것은 정확성이 아니라 읽히는지다.** 부품 이름이 겹쳐 안 보이거나, 원판이 너무 작게 그려져 판단이 안 된다면 그것이 결함이다.

### 2-4. 고정하고 다시 계산한다

1. 부품 목록에서 하나를 골라 `이 원판에 고정` 을 켠다.
2. `고정하고 다시 계산` 을 누른다.
3. **확인**: 고정한 부품이 지정한 원판에 그대로 놓인다.
4. **확인**: 개정 이력에 새 줄이 쌓이고 이전 개정이 그대로 남는다.

**업무 감각으로 볼 것**: 실제로 손보고 싶은 이유가 이 방식으로 해결되는가. "이 부품은 저 판에 같이" 로 충분한지, "여기 이 자리에" 가 필요한지를 판단해 알려 주면 `D2-B05-J` 를 다시 연다.

### 2-5. 지킬 수 없는 고정은 거부된다

1. 부품 전부를 두 번째 원판에 고정하고 다시 계산한다.
2. **확인**: 첫 원판이 빌 수 없으므로 실패로 끝나고 이유가 화면에 보인다. 잘못된 배치가 저장되지 않는다.

### 2-6. 승인하면 잠긴다

1. 결과가 마음에 들면 `승인` 을 누른다.
2. **확인**: 상태가 `승인` 이 되고 승인자가 표시된다.
3. **확인**: `다시 계산` 과 `승인` 버튼이 사라진다.
4. **확인**: 목록에서도 `승인` 으로 보인다.

### 2-7. 미배치가 있으면 승인할 수 없다

1. 원판보다 큰 절곡 작업이 있는 수주로 재단을 돌린다.
2. **확인**: 노란 알림에 배치하지 못한 부품과 사유가 나온다.
3. **확인**: `승인` 버튼이 눌리지 않는다.

### 2-8. 권한

1. `cutting.approve` 가 없는 계정으로 들어간다.
2. **확인**: 재단 상세에서 `승인` 버튼이 보이지 않는다.
3. **확인**: `cutting.optimize` 가 없는 계정은 상단 `생산·절단` 메뉴 자체가 보이지 않는다.
