## 3. 입력 경계 확인

- 재질·두께 코드는 영문·숫자·`-`·`_` 2~50자만 허용한다.
- 밀도와 두께는 0보다 커야 하고, 내측반경은 0 이상이다.
- 화면 입력은 소수 최대 3자리이며 API·DB는 `Decimal(18,6)` canonical 문자열을 보존한다.
- 재질 코드, 두께 코드, 두께 값은 등록 후 변경하지 않는다.

## 4. 이번 단계의 의도된 제한

- 새 두께의 연신율·컷 깊이·제한각을 작성·검토·발행하는 화면은 `P2-A04`에서 구현한다.
- 따라서 이번 단계에서 새 두께가 `계산 기준 필요`이고 설계에서 선택되지 않는 것은 정상이다.
- 원판 규격·중량·가격은 `P2-A05`, 실제 기계 연동은 P3 범위다.

## 5. 검수 완료 기준

`A03-T01~T11`이 기대 결과와 일치하면 P2-A03 화면 검수를 승인한다. 불일치가 있으면 테스트 ID, 화면, 입력값과 실제 결과를 기록해 수정 후 재검증한다.
