# 두께 등록 마법사 화면 테스트 가이드

> 대상: [두께 등록 마법사](./work-items/material-variant-wizard.md)
>
> 작성일: 2026-09-13
>
> 계정: [로컬 화면 테스트 계정](./local-screen-test-account.md) — 승인 권한이 있어 `등록하고 게시` 가 보인다

## 1. 새 재질부터 게시까지 한 자리에서

| 단계 | 기대 |
|---|---|
| 1-1 | `기준정보 > 재질·두께` → `새 재질` 로 코드 `T-SUS`, 이름 `테스트 SUS`, 밀도 `7930` 등록 | 알림 없이 재질 상세가 열리고 **두께 항목 탭이 이미 선택**되어 있다. "등록된 두께가 없습니다" 안내가 보인다 |
| 1-2 | `두께 추가` | 팝업 상단에 `① 두께 정보 → ② 계산 기준 → ③ 확인·게시` 진행 표시. 버튼은 `취소 / 두께만 등록 / 다음: 계산 기준` |
| 1-3 | 코드 `t-sus-12`, 이름 `SUS 1.2T`, 두께 `1.2`, 내측반경 `1.2` → `다음: 계산 기준` | ②로 넘어가고 상단에 방금 입력한 두께 요약이 보인다. 내측 절곡 반경에 `1.2` 가 미리 들어 있다 |
| 1-4 | 제한각 `135`, FIX 연신 `1.2 / 0.8 / 2`, RATIO 컷 깊이 `0.5 / 0.5 / 0` → `다음: 확인` | ③에 두께·계산 방식·값 요약과 효력 시작 시각(현재)이 보인다. 버튼 `등록하고 게시` |
| 1-5 | `등록하고 게시` | 체크 목록 `두께 등록 → 계산 기준 초안 저장 → 검토 요청 → 게시` 가 차례로 완료되고 팝업이 닫힌다. 목록 위에 "…게시했습니다. 이제 설계에서 선택할 수 있습니다" 메시지. 행의 단계 표시가 4개 모두 완료 |
| 1-6 | `설계·도면` → 새 초안의 재질 선택 | `테스트 SUS · SUS 1.2T` 가 선택된다 |

## 2. 두께만 먼저 등록하고 나중에 이어서

| 단계 | 기대 |
|---|---|
| 2-1 | `두께 추가` → 코드 `t-sus-20`, 이름 `SUS 2T`, 두께 `2`, 반경 `2` → `두께만 등록` | 팝업이 닫히고 행에 `두께 등록 ✓ · 계산 기준(진행) · 검토 · 게시` 와 `계산 기준 작성` 버튼 |
| 2-2 | `계산 기준 작성` | 마법사가 ②단계부터 열린다(①은 생략). 값 입력 → `다음: 확인` → `등록하고 게시` | 행이 완료 상태가 된다 |

## 3. 중간 실패와 복구

| 단계 | 기대 |
|---|---|
| 3-1 | 계산 기준 페이지에서 새 두께 `SUS 3T` 를 만든 뒤(`두께만 등록`) `계산 기준` 링크로 가서 `새 개정 만들기` 로 초안만 저장 | 재질 상세로 돌아오면 행에 `검토 요청 후 게시` 버튼과 "초안 r1 작성됨 · 검토 요청이 남았습니다" |
| 3-2 | `검토 요청 후 게시` | 페이지 이동 없이 행이 완료 상태로 바뀐다. 변경 요약을 비워 두었어도 `최초 계산 기준 등록` 으로 채워져 진행된다 |

## 4. 승인 권한이 없는 계정 (선택)

`DESIGNER` 역할만 가진 계정으로 1-2~1-5 를 반복하면 ③ 버튼이 `등록하고 검토 요청` 이고, 완료 메시지가 "승인자가 게시하면 설계에서 선택할 수 있습니다" 다. 행에는 "r1 검토 중 · 승인자의 게시를 기다립니다" 가 보이고 버튼이 없다.

## 5. 기존 화면

- 두께 `수정` 팝업은 그대로다(코드·두께 읽기 전용). 저장하면 알림 대신 목록 위 한 줄 메시지
- 계산 기준 페이지의 개정 편집·검토·게시·반려·미리보기는 바뀌지 않았다(`P2-A04` 가이드 그대로)
