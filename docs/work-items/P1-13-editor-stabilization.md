## 완료 범위

- 서버 초안별 편집 상태, 최근 초안 전환, 자동 저장, 낙관적 잠금 충돌, 로컬 복구를 유지했다.
- Undo/Redo는 최대 50개 plain snapshot으로 제한하고 120회 연속 편집 시험을 추가했다.
- 입력 컨트롤을 제외한 작업 화면에서 `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`, `Ctrl+Y`, `Escape`를 지원한다.
- 원호·박스·패널 변경도 동일 history와 서버 문서 v2 저장 경로를 사용한다.
- 브라우저 기본 확인창은 사용하지 않고 모든 확인·알림은 공통 팝업을 사용한다.

## 검증 기준

| 항목 | 자동 검증 |
|---|---|
| 장시간 편집 | 120회 변경 후 최근 50개 checkpoint만 보존 |
| 단축키 | Playwright에서 길이 변경→Undo→Redo 결과 확인 |
| 다중 화면 | 기존 초안 충돌·서버본 재읽기·새 초안 복사 E2E 유지 |
| 복구 | 네트워크 실패 후 IndexedDB 복구본 적용 E2E 유지 |

삭제 단축키는 오조작 위험이 있어 P1 기준선에 넣지 않았다. 삭제는 화면 명령과 공통 확인 팝업을 사용한다.
