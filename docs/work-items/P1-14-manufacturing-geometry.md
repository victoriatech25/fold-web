## 확정 기준

화면 표시용 Konva/Three.js 좌표와 제작 출력 좌표를 분리했다. 제작 기준은 `manufacturing-geometry-v1`, 단위는 mm이며 모든 값은 유한수와 소수 6자리 이내로 정규화한다.

| 레이어 | 의미 |
|---|---|
| `CUT` | 주 단면 전개 외곽 절단선 |
| `PANEL_CUT` | 연결 패널 전개 외곽 절단선 |
| `V_CUT` | V-CUT 절곡선 |
| `A_CUT` | A-CUT 절곡선 |
| `BEND` | 컷 없는 일반 절곡선 |
| `PROFILE_REFERENCE` | 확장용 단면 참조선 |

일반 도면은 닫힌 직사각 전개 외곽과 절곡선을 생성한다. 박스는 두 단면의 교차 직선을 바닥 가로·세로로 자동 판정해 닫힌 외곽과 절곡선을 생성하며 제품 길이를 요구하지 않는다. 박스 연결 패널의 제작 길이는 host 단면 반대편 바닥 치수를 사용한다. 패널은 주 전개도 오른쪽에 20 mm 간격으로 독립 배치한다. 일반 도면의 제품 길이 오류, 빈 entity, 비유한 좌표, 열린 주 외곽은 출력 전에 차단한다.

## 검증

- 일반·박스·패널의 좌표, bounds, 레이어와 외곽 폐합 단위 시험
- 잘못된 제품 길이와 비어 있는 단면 거부 시험
- 화면 geometry 변경과 무관한 결정적 결과 및 DXF writer 입력 계약 시험
