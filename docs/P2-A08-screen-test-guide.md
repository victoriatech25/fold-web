# P2-A08 절곡 작업 스냅샷 화면 테스트 가이드

> 상태: `READY_FOR_USER_VERIFY` (2026-08-17)
>
> 담당자·검수자: 사용자 본인
>
> 테스트 주소: `http://localhost:3001`

## 1. 검수 범위

게시 절곡 개정의 주문 snapshot 추가, 고객 표시정보 고정, 수량·직접 변수·재질·원판 변경, 작업 복사·정렬·제거, 새로고침 복원, 취소/권한/충돌/감사와 반응형 화면을 확인한다.

계산 결과·면적·중량·가격·VAT는 `P2-A09`, 승인·생산 상태는 `P2-A10` 범위다. A08 화면에서는 작업 상태가 `계산 전`으로만 보여야 한다.

## 3. 기본 수명주기

### `A08-UI-01` 게시 개정 추가와 고객정보 고정

1. `업무 > 수주·작업`에서 `SCREEN-PRICE` 거래처로 새 수주를 만든다.
2. 상세 하단 `절곡 작업 추가`를 누른다.
3. 검색란에 `SCREEN-FOLD-L`을 입력하고 `화면검수 ㄱ자 절곡`을 선택해 추가한다.

기대 결과:

- `작업 1`, 템플릿 코드, 개정 1, 수량 2, 알루미늄 1T, 블록·선 수와 `계산 전`이 표시된다.
- `첫 절곡 작업 추가 시점의 고객정보가 고정되었습니다.` 안내가 보인다.
- 거래처·고객 현장·거래처 담당자는 비활성화되고, 사내 담당자·납기·외부 참조·내부 비고는 계속 수정할 수 있다.
- 작업을 모두 제거해도 고객정보 잠금은 풀리지 않는다.

### `A08-UI-02` 주문 입력 변경

1. 작업 카드를 선택한다.
2. 수량을 `5`, 변수 `A`를 `250`으로 변경한다.
3. 재질·두께를 `알루미늄 2T`, 원판을 해당 기본 원판으로 선택한다.
4. `작업 입력 저장`을 누르고 새로고침한다.

기대 결과:

- 카드가 수량 5, 알루미늄 2T와 선택 원판으로 바뀐다.
- 새로고침 후 수량·A 값·재질·원판이 동일하다.
- 수식이 있는 변수는 읽기 전용이어야 한다.
- geometry·절곡선·수식 구조를 편집하는 UI는 없어야 한다.

### `A08-UI-03` 복사·정렬·제거

1. 작업 1의 `복사`를 눌러 작업 2를 만든다.
2. 작업 2의 `위로`를 눌러 첫 번째로 이동한다.
3. 새로고침해 순서가 유지되는지 확인한다.
4. 작업 2의 `제거`를 누르고 공통 확인 팝업에서 제거한다.

기대 결과:

- 사본은 현재 주문 입력을 그대로 가지며 새 line number를 받는다.
- 순서 변경 후 작업 번호 자체는 바뀌지 않는다.
- 제거한 작업은 일반 목록에서 사라지고 남은 작업 번호는 재사용되지 않는다.
- 수주 상단 `복사`는 A07 계약대로 헤더만 복사하고 절곡 작업은 복사하지 않는다.

## 4. 불변성·충돌·상태 검수

### `A08-IMMUTABLE-01` 원본과 기준정보 변경

1. 주문 작업의 템플릿 코드·개정·checksum 앞 12자, 재질명과 입력값을 기록한다.
2. 별도 테스트 템플릿을 게시해 주문에 추가한 뒤 템플릿 이름 변경 또는 새 개정 게시를 수행한다.
3. 거래처·재질 표시정보도 테스트 범위에서 변경한 뒤 기존 주문을 다시 연다.

기대 결과: 기존 주문의 snapshot 이름·형상 요약·재질·변수·checksum은 추가 당시 값으로 유지된다. 원본의 최신 값을 다시 결합하지 않는다.

### `A08-CONFLICT-01` 두 탭 동시 변경

1. 같은 수주를 두 탭에서 연다.
2. 첫 탭에서 수량을 저장한다.
3. 두 번째 탭에서 다른 수량을 저장한다.

기대 결과: 늦은 요청은 `409` 충돌 안내를 표시하고 최신 화면을 다시 읽도록 안내한다. 첫 탭의 값이 덮어써지지 않는다.

### `A08-STATE-01` 취소와 권한

- 취소 수주에는 `절곡 작업 추가`, 입력 저장, 복사·정렬·제거 버튼이 없어야 한다.
- `order.read`만 있는 사용자는 작업을 읽지만 변경 버튼은 없어야 한다.
- `order.read`가 없거나 다른 조직의 수주/개정/작업 UUID에는 접근할 수 없어야 한다.
- 신규 선택에는 활성 템플릿의 현재 게시 개정만 나타나야 한다.

## 5. 감사·반응형 검수

### `A08-AUDIT-01` 감사 로그

`관리 > 감사 로그`에서 다음 이벤트를 확인한다.

- 수주 고객정보 고정
- 수주 절곡 작업 추가·변경·복사·순서 변경·제거

행위자, 수주/작업 ID, request ID, 출처 개정과 checksum, 변경 필드가 기록되어야 한다. 2MB 문서 본문 전체는 감사 payload에 없어야 한다.

### `A08-RWD-01` 화면 폭

브라우저 폭 `390px`, `768px`, `1280px`, `1920px`에서 주문 상세를 확인한다.

- 전체 viewport 가로 스크롤이 없어야 한다.
- 모바일에서는 작업 카드 다음에 선택 작업 입력이 자연스럽게 쌓여야 한다.
- 템플릿 선택 목록을 스크롤하고 추가 버튼에 접근할 수 있어야 한다.
- 공통 제거/충돌 팝업의 본문과 버튼에 접근할 수 있어야 한다.
