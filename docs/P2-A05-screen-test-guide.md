## 3. snapshot 추가 확인

기존 초안을 열어 둔 상태에서 원판 마스터의 trim·이름을 수정해도 이미 저장된 초안의 물리 snapshot은 자동 변경되지 않는다. 새 원판을 명시적으로 다시 선택했을 때만 최신 물리값으로 교체된다. 비활성 원판도 기존 초안 재열기에는 남지만 새 선택 목록에서는 제외된다.

## 4. 범위 경계

- 이번 화면의 구매가는 내부 참고값이다. 고객 판매가·절곡비·V-CUT비는 `P2-A06`에서 구현한다.
- 실제 재고 수량, 필요 원판 장수, 재단 배치·수율, 잔재 실물은 아직 계산하지 않는다.
- 모든 알림·확인은 브라우저 시스템 팝업이 아니라 공통 팝업이다.
